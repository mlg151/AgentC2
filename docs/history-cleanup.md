# Saved conversation cleanup

AgentC2 can preview and delete verified inactive Codex and Claude conversation histories on a configured SSH host. The desktop cleanup dialog handles single or bulk deletion, shows eligibility and estimated bytes, requires an explicit confirmation, and reports partial or uncertain outcomes. Optional retention runs while AgentC2 is open, in bounded daily batches, and excludes pinned, live, stale, ambiguous, or unknown-format records. Deleting history is separate from detaching or stopping a managed terminal and from archiving a Git worktree.

Codex uses its native `codex delete --force` operation for supported local thread storage. Claude uses a version-aware adapter for verified session transcripts and supported per-session sidecars and index entries. Unknown layouts and shared/unscoped data are retained. AgentC2 never calls arbitrary deletion paths or deletes a project repository, credentials, or a worktree as part of history cleanup. These operations are not secure erasure.

Antigravity CLI 1.4.4 has no documented noninteractive, conversation-ID deletion command. Its current local trajectory layout uses per-conversation SQLite databases in `~/.gemini/antigravity-cli/conversations/`, matching `brain/` directories, and a shared `conversation_summaries.db` index. AgentC2 discovers the current databases and retains recognition of older `.pb` histories, but it does not delete either layout: unlinking a database alone would leave provider-managed references and sidecars. The provider's [changelog](https://github.com/google-antigravity/antigravity-cli/blob/main/CHANGELOG.md) also records cleanup of orphaned annotations and worktrees when conversations are deleted through the CLI.

For manual deletion in CLI 1.4.4, open `agy` from the original project directory, find the conversation in `/resume`, press **F4** (or the configured `item.delete` key), and confirm. The [installed CLI changelog](https://github.com/google-antigravity/antigravity-cli/blob/main/CHANGELOG.md) changed the default from Ctrl+Delete to F4 in 1.1.13; the [resume command page](https://antigravity.google/docs/cli/commands/resume/) still shows the older key. Review the associated worktree and back up any uncommitted or untracked work before using the provider action: an [Antigravity CLI issue](https://github.com/google-antigravity/antigravity-cli/issues/388) reports conversation deletion removing an entire worktree. Refresh AgentC2 afterward. This provider action is outside AgentC2’s automated retention policy.

Validation for the supported adapters includes disposable-home Python fixtures, isolated SSH/Electron cleanup checks, and the desktop/companion regression suite. With the authenticated Antigravity CLI 1.4.4, a disposable conversation was created and deleted through exact-ID `/resume` search, F4, and confirmation. Read-only SQLite and filesystem checks confirmed that its trajectory database, matching brain directory, and shared summary entry disappeared. The test used a disposable project and did not exercise deletion of a conversation with an associated worktree or establish that unattended deletion is safe.
