# Provider signal and telemetry support

AgentC2 keeps provider signals separate from terminal-output guesses. Codex turn completion and Claude turn, failure, and input hooks are confirmed provider events when the launch preset enables hooks. Terminal text that resembles a prompt remains **inferred**. Antigravity 1.4.4 has no verified structured hook in this release, so its provider events and usage are **unsupported**; process exit remains direct process evidence. Hook records contain only event type, time, provider session/turn identifiers, and a stable event ID. They do not store prompts, tool arguments, credentials, or assistant messages.

For Codex CLI 0.162.1, AgentC2 reads bounded token-count metadata from the rollout file named by the read-only thread index. It computes context percentage from reported latest input tokens and the reported model context-window size. It shows a token rate only when two cumulative samples span at least five seconds within the last minute. Codex cost is **unknown** because CLI subscription and custom-provider billing cannot be inferred from token counts.

For Claude Code 2.1.281, AgentC2 reads bounded assistant usage and cost-state metadata from the provider's session JSONL. Repeated records for the same assistant message are counted once for the displayed recent token rate. A USD session estimate is shown only when a cost-state after the latest assistant record explicitly says all model costs are known. Claude context remains **unknown** in this adapter: message token usage alone does not establish the current context-window capacity, especially with model switches, extended windows, and compaction. Claude's [status-line schema](https://code.claude.com/docs/en/statusline) reports that capacity, but replacing a user's status-line configuration just to collect telemetry would alter their CLI experience.

Metrics without a usable provider record display **unknown**. A last sample older than two minutes displays **stale**, not a current percentage or rate. When a reported context percentage reaches 75% or 90%, the roster meter and pane label show warning or critical state. Output activity bars are received terminal bytes per ten seconds; they are never labeled as token velocity. No fleet-wide spend total is shown while any unit lacks a trustworthy cost value. Provider transcript content is read only in bounded local scans on the SSH host; only numeric metadata and provenance reach the desktop. The remote helper is ephemeral and writes no telemetry cache.

The Codex [notification payload](https://learn.chatgpt.com/docs/config-file/config-advanced#notifications) supplies thread and turn IDs for stable event identity. Claude's [hook input](https://code.claude.com/docs/en/hooks#common-input-fields) supplies session and prompt IDs. Hooks remain advisory telemetry and never approve or deny an agent action.
